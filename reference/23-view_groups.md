# 表示グループ

「ゴールド会員のみ閲覧できる特別商品」など商品の表示をグループによって設定する機能

## GET {{api_url}}/api/v1/view_groups/1

**レスポンス例（200 OK）:**

```json
{
  "view_group": {
    "id": 1,
    "name": "販路規制 ネット販売のみ会員"
  }
}
```

## GET {{api_url}}/api/v1/view_groups

**URIパラメータ**

| パラメータ名 | 名称 | 型 | 最大桁数 | 内容 |
| --- | --- | --- | --- | --- |
| limit | limit | 整数 |  | 指定した件数分のデータを取得します。指定なしの場合は20件、最大100件 |
| offset | offset | 整数 |  | 指定した値+1件目のデータからlimit分を取得します。指定しない場合は0 |
| ids | ID複数 | 整数 |  | 複数の表示グループIDをカンマ区切りで指定 |
| fields | フィールド | 文字列 |  | 取得したいフィールドカンマ区切りで指定 |
| name | セット名 | 文字列 | 255 |  |

## 拡張パラメータによる高度な絞り込み

拡張パラメータを使用することで、より高度な絞り込みが可能です。

詳しくは、[パラメータ](../docs/04-parameters.md)の「拡張パラメータ」欄をご参照ください。

**レスポンス例（200 OK）:**

```json
{
  "view_groups": [
    {
      "id": 1,
      "name": "販路規制 ネット販売のみ会員"
    },
    {
      "id": 2,
      "name": "販路規制 ブランドB"
    },
    {
      "id": 3,
      "name": "東日本のお客様"
    },
    {
      "id": 4,
      "name": "西日本のお客様"
    }
  ],
  "meta": {
    "limit": 20,
    "offset": 0,
    "total": 4
  }
}
```
