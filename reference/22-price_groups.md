# 価格グループ

個々の会員に対して商品の価格を定めるのではなくグループとしてまとめて設定できる機能

## GET {{api_url}}/api/v1/price_groups/1

**レスポンス例（200 OK）:**

```json
{
  "price_group": {
    "id": "1",
    "name": "リピート会員",
    "rate": "0.9000"
  }
}
```

## GET {{api_url}}/api/v1/price_groups

**URIパラメータ**

| パラメータ名 | 名称 | 型 | 最大桁数 | 内容 |
| --- | --- | --- | --- | --- |
| limit | limit | 整数 |  | 指定した件数分のデータを取得します。指定なしの場合は20件、最大100件 |
| offset | offset | 整数 |  | 指定した値+1件目のデータからlimit分を取得します。指定しない場合は0 |
| ids | ID複数 | 整数 |  | 複数の価格グループIDをカンマ区切りで指定 |
| fields | フィールド | 文字列 |  | 取得したいフィールドカンマ区切りで指定 |
| name | セット名 | 文字列 | 255 |  |

## 拡張パラメータによる高度な絞り込み

拡張パラメータを使用することで、より高度な絞り込みが可能です。

詳しくは、[パラメータ](../docs/04-parameters.md)の「拡張パラメータ」欄をご参照ください。

**レスポンス例（200 OK）:**

```json
{
  "price_groups": [
    {
      "id": "1",
      "name": "リピート会員",
      "rate": "0.9000"
    },
    {
      "id": "2",
      "name": "特別会員",
      "rate": "0.7000"
    },
    {
      "id": "3",
      "name": "グループ名は自由につけられます",
      "rate": "0.6000"
    },
    {
      "id": "4",
      "name": "販売掛率もいつでも変更できます",
      "rate": "0.5500"
    },
    {
      "id": "n",
      "name": "非会員のお客様",
      "rate": "1.0000"
    }
  ],
  "meta": {
    "limit": 20,
    "offset": 0,
    "total": 5
  }
}
```
