# アカウント情報

認証（プライベートアクセストークンまたはOAuth認証）情報に紐づくリソースオーナーのアカウント情報

## GET {{api_url}}/api/v1/user

**レスポンス一覧**

| **Key** | **名称** | **型** | **最大桁数** | **内容** |
| --- | --- | --- | --- | --- |
| id | アカウントID | 整数 | 11 | 変更不可で一意なアプリストアアカウントID |
| email | メールアドレス | 文字列 | 255 | 変更可能で一意なメールアドレス |
| site_id | サイトID | 整数 | 11 | 変更不可で一意なサイトID |
| site_url | サイトURL | 文字列 | 255 | ※変更される可能性があります |
| company_name | 企業名 | 文字列 | 255 | ※変更される可能性があります |

**レスポンス例（200 OK）:**

```json
{
  "user": {
    "id": 1,
    "email": "postman@dai.co.jp",
    "site_id": 1,
    "site_url": "test.bcart.jp",
    "company_name": "株式会社テスト"
  }
}
```
